🐍 Ouroboros 衔尾蛇

🟢 Online Demo

项目介绍

这是一款基于 Vue 3 + Phaser 4 开发的衔尾蛇生存游戏，Game Jam 作品。玩家控制一条不断转动的蛇，环绕敌人形成闭环，让首尾再次相遇，从而捕获敌人。

项目背景

这个项目从 Game Jam 原始代码中独立重构而来，只保留「衔尾蛇」核心玩法，并用 Vue 3 + Phaser 4 + TypeScript 重新组织前端架构，同时支持 Web、Windows 桌面和 Android 多端运行。

技术栈

Vue 3 Phaser 4 TypeScript Vite GitHub Pages

核心功能

  • 🐍 环绕敌人形成闭环，让首尾再次相遇并捕获敌人。
  • 👾 净化积分首次达到 15 分时，吞噬者 Boss 登场。
  • 💠 环绕捕获外置核心，破坏 Boss 护盾。
  • 🎵 Boss 战切换专属背景音乐，冲刺、破甲、击败均有独立音效反馈。
  • 📱 Web、Windows、Android 多平台支持。
