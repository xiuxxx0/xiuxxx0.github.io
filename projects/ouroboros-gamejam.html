🐍 圈一圈（Ouroboros）

🏆 2026 BOKE VIBE JAM 一等奖 · 🟢 Online Demo

项目介绍

《圈一圈（Ouroboros）》是一款以“衔尾蛇”为灵感设计的动作游戏。玩家通过控制不断延伸的蛇身形成闭环，在循环中完成战斗与净化。游戏围绕“连接、循环与成长”的主题展开，将简单的环形机制转化为核心玩法体验。

项目背景

本项目是 2026 BOKE VIBE JAM 一等奖作品，基于 Vue 3 + Phaser + TypeScript 开发，采用模块化架构设计，由团队协作完成，并支持 Web、Windows 与 Android 多端运行。

技术栈

Vue 3 TypeScript Phaser Vite Electron Capacitor GitHub Pages

游戏特色

  • 🔄 独特的闭环战斗机制：控制蛇身形成闭环，捕获敌人完成净化。
  • ⚔️ Boss 战与阶段式挑战：净化积分首次达到 15 分时噬环者登场，闭环捕获外置核心以破坏护甲。
  • 🎵 音频反馈与动画演出：Boss 战切换专属背景音乐，冲刺、破甲、击败均有独立声音反馈。
  • 🖥️ Web / Windows / Android 多端支持。
  • 👥 团队协作开发，完整工程化流程。

操作说明

  • 🖱 鼠标点击或拖动、触屏拖动：连续转向。
  • ⌨️ WASD / 方向键：四方向转向。
  • ⏸️ Space / Esc / P：暂停或继续。
  • 📋 暂停菜单：继续游戏、结束本局、调整总音量或静音。
