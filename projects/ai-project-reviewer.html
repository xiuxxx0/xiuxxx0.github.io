🤖 RepoCourse · AI 项目复盘助手

🧪 Python CLI · PyPI 包 repocourse

项目介绍

让 AI 辅助编程时代，每一次「完成项目」都变成「理解项目」。输入一个代码项目，自动生成技术复盘《README复盘.md》、个人成长反馈《learning_report.md》、知识图谱与个性化学习计划。

解决的问题

  • ❓ 不知道自己真正学会了什么 — 项目跑通了，知识未必进了脑子。
  • 🤖 不清楚哪些部分依赖 AI — 哪些代码是 AI 写的，哪些是你自己设计的。
  • 🧭 不知道下一步应该学什么 — 缺少个性化的学习反馈。

核心能力

  • 🔍 项目理解：Repo Scanner · Code Understanding Agent — 分析项目结构、技术栈与核心逻辑。
  • 🤝 AI 协作分析：基于 Git / Agent 日志等证据，复盘你与 AI 的分工（非作弊检测）。
  • 🎯 技能评估：技能档案 × 项目证据 × Quiz × AI 贡献，评估真实掌握程度。
  • 📈 学习反馈：学习盲区、游戏技能树、下一步学习计划。

快速开始

pip install repocourse
apr review .

输出产物

  • README复盘.md：技术复盘 8 大板块 + 技能评估 + 学习路线 + 证据附录。
  • learning_report.md：学到什么 / AI 协作 / 盲区 / 学习路线。
  • knowledge_graph：知识图谱 json / html / canvas / mindmap 多格式。
  • learning_plan.json：个性化学习计划。
